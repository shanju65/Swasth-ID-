# 📌 Overview

**Swasth ID** is an AI-powered digital healthcare platform designed to simplify patient record management and improve healthcare accessibility.

The system provides every patient with a **unique QR-based Health ID** that allows hospitals and doctors to securely access medical records with proper authorization.

The platform combines **Flutter**, **Django**, **PostgreSQL**, and **Artificial Intelligence** to deliver a modern healthcare solution.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/vishalgokul504/swasth-id.git
```

## Backend

```bash
cd backend

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

## Flutter App

```bash
cd swasth_id_app

flutter pub get

flutter run
```
